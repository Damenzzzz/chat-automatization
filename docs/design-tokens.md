# Дизайн-токены

Источник правды — `apps/web/src/app/globals.css`. Здесь смысл токенов и правила.

## Главная идея

Кабинет белый и серый. **Густой графит значит «нужен человек»:** ожидающий покупатель, перехваченный диалог, ответ менеджера, главное действие на экране. Всё, что бот делает сам, остаётся серым. Цвет сообщает, кто сейчас отвечает за покупателя, а не украшает страницу.

Единственный момент, ради которого всё остальное тихое: при перехвате шапка диалога переворачивается из серой в графитовую.

## Цвета

| Токен | Значение | Для чего | Контраст |
| --- | --- | --- | --- |
| `paper` | `#ffffff` | рабочая область, поля | |
| `mist` | `#f3f4f5` | боковое меню, шапка диалога с ботом | |
| `haze` | `#e6e8ea` | реплики бота, активный пункт меню, столбцы графика | |
| `line` | `#d6d9dc` | разделители (не для полей ввода) | |
| `control` | `#868c92` | рамки полей и кнопок | 3,4:1 на белом |
| `steel` | `#565c62` | вторичный текст | 6,8:1 на paper, 6,1:1 на mist, 5,5:1 на haze |
| `ink` | `#1c1f22` | текст и всё, что требует человека | 16,6:1 на paper |
| `alert` | `#b3261e` | только ошибки | 6,5:1 на paper, 5,8:1 на alert-soft |
| `alert-soft` | `#fbeeed` | фон ошибки | |

Другие цвета не добавляем: успех — графит и значок, а не зелёный.

## Шрифты

- **Golos Text** — весь текст. Цифры в таблицах и суммах — через утилиту `tnum`.
- **Commissioner** с осью `FLAR 100` — только заголовки и крупные суммы (`h1–h3`, `.display`). Табличных цифр в нём нет, поэтому в колонки его не ставим.

Оба подключены через `next/font` с `cyrillic-ext` и `latin-ext`: там лежат казахские буквы и ₸. Подмножество `cyrillic-ext` само по себе ничего не гарантирует: у Manrope, Wix Madefor и Sofia Sans оно заявлено, а `ә ғ қ ң` нет. Новый шрифт проверять по таблице символов файла.

Шкала: 13, 14, 16, 20, 25, 32, 52 px. Поля ввода не меньше 16 px, иначе iOS масштабирует страницу.

## Форма

- Радиусы: 4 px метки, 8 px поля и кнопки, 14 px реплики в чате. Карточек с тенью нет: разделы разделяет воздух и линия `line`.
- Цель нажатия на телефоне не меньше 44 px.
- Фокус: сплошная линия 2 px цвета `ink` со смещением 2 px, на графитовом фоне (`.on-ink`) — белая.
- Движение только в ответ на действие человека, `prefers-reduced-motion` отключает всё.

## Текст

Простые слова от лица пользователя, предложения с прописной только в начале. Без капса, без надписей над заголовками, без стрелок в кнопках. Ошибка говорит, что случилось и что сделать.
