# Дизайн-токены

> Заглушка. Заполняется на шаге с лендингом и кабинетом.

Источник правды для токенов — CSS-переменные в `apps/web/src/app/globals.css` (тема shadcn/ui, Tailwind 4 `@theme`). Здесь фиксируем смысл каждого токена и правила использования.

| Группа | Токены | Статус |
| --- | --- | --- |
| Цвета | `--background`, `--foreground`, `--primary`, `--muted`, `--destructive`, … | дефолт shadcn (neutral) |
| Шрифт | `--font-sans` — Geist (latin, cyrillic, cyrillic-ext для казахских букв) | выбран |
| Радиусы | `--radius` | дефолт shadcn |
