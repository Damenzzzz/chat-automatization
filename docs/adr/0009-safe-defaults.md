# 0009. Безопасные значения по умолчанию и потолки расхода

- Статус: принято
- Дата: 2026-11-10

## Контекст

Аудит показал, что сервис открывается при ошибке в конфигурации: `ENV` по умолчанию был `dev` (код входа уходил в ответ API), `.env.example` с известным `JWT_SECRET` всегда подгружался в compose, демо-магазин давал любому посетителю права владельца, а чат лендинга, песочница и виджет позволяли тратить деньги на модель без общего потолка. Лимиты по IP считались по первому значению `X-Forwarded-For`, которое задаёт клиент.

## Решение

- `ENV` обязателен; при `ENV=prod` сервис не стартует с `JWT_SECRET` из `.env.example`. `/docs` и `/openapi.json` в проде выключены, добавлен `/ready` (Postgres и Redis).
- Демо-сессия только читает: любой не-GET запрос владельца демо-магазина отклоняется с `demo_read_only`, кроме песочницы, перехвата и ответа в диалоге, черновика, статуса заявки и отметки уведомления (`DEMO_WRITABLE` в `app/auth/deps.py`). Вход админа под магазином ограничение не затрагивает.
- IP клиента (`app/core/net.py`): адрес соединения, если он публичный; иначе самый правый публичный адрес из `X-Forwarded-For`. Подставленный клиентом заголовок лимит не обходит, а за внутренними прокси виден настоящий адрес. За CDN с публичными адресами клиенты одного узла делят лимит.
- Потолки (`app/core/ratelimit.py`): чат лендинга `DEMO_CHAT_DAILY_LIMIT` в сутки на весь сервис, песочница `SANDBOX_MESSAGES_PER_HOUR` и `SANDBOX_AUTOTESTS_PER_HOUR` на магазин, виджет `WIDGET_CHANNEL_MESSAGES_PER_HOUR` на канал, черновики ответа 60 в час на магазин.
- Порты Postgres, Redis, MinIO и ML в compose слушают только `127.0.0.1`. Кабинет отдаёт `X-Frame-Options`, `frame-ancestors 'none'`, `nosniff`, HSTS.

## Последствия

- Локальный запуск без `ENV` падает с понятной ошибкой валидации; тесты задают `ENV=test`.
- В демо нельзя менять профиль бота, каналы, команду и каталог: кабинет показывает текст `demo_read_only`.
- Не сделано и остаётся в плане: подписанные сервером сессии виджета, лимит кодов входа по IP, RLS для таблиц `agent_state`, проверка `tenants.status = suspended`, отзыв access-токена при выходе.
