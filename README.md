# Satushy

AI-консультант для магазинов Казахстана: знает весь каталог и отвечает покупателям в WhatsApp, Instagram, Telegram и на сайте.

- Спецификация MVP — [SPEC.md](SPEC.md)
- Памятка для разработки — [CLAUDE.md](CLAUDE.md)

```bash
cp .env.example .env
make up
```

Кабинет после `make up` открыт только на этом компьютере: <http://localhost:3000>. В сеть порты сервиса не смотрят, наружу выложен один лендинг.

## Сервисы кабинета

Кроме бота в разделе «Сервисы» есть автоматизации, которые владелец включает и настраивает сам:

| Сервис | Что делает |
| --- | --- |
| Сводка за день | Присылает в Telegram итоги вчерашнего дня и то, что ждёт ответа |
| Контроль остатков | Сообщает, когда товар заканчивается |
| Возврат покупателя | Напоминает о себе покупателю, который спросил про товар и замолчал |
| Напоминания о заявках | Напоминает команде о заявке без ответа и о заявке с подошедшим сроком |

У каждого есть проверка без отправки, запуск вручную и история. Как это устроено — [docs/adr/0013-automations.md](docs/adr/0013-automations.md).

## Лендинг

Сайт команды — статическая сборка лендинга из `apps/web` без кабинета и API (`LANDING_ONLY=1`); заявки с формы принимает функция из `apps/landing/lambda`.

```bash
make landing-test                                  # тесты сайта и функции заявок
make landing-deploy LEADS_EMAIL=you@example.com    # первый запуск: S3, CloudFront, функция заявок
make landing-deploy                                # обновить сайт
```

Как это устроено и почему — [docs/adr/0012-landing-on-aws.md](docs/adr/0012-landing-on-aws.md).
